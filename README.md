# Profile Card

A responsive, accessible Profile Card built with **HTML, CSS, and vanilla JavaScript**. All visible elements include `data-testid` attributes for automated testing.

## Features

- **Semantic HTML**: `<article>`, `<header>`, `<figure>`, `<nav>`, `<section>`  
- **Avatar** with proper `alt` text  
- **Current time** in milliseconds (`Date.now()`)  
- **Social links** open in new tabs with `rel="noopener noreferrer"`  
- **Hobbies** and **Dislikes** as separate lists  
- **Responsive layout**: stacks vertically on mobile, switches to two columns on larger screens  
- **Keyboard-focusable links** for accessibility  

## Project Structure
